# Моно — интернет-магазин одежды (лендинг с каталогом и корзиной)

Одностраничный сайт вымышленного бренда базовой одежды. Учебный проект для портфолио: на нём видно, как работает магазин, а не только как он выглядит.

**Демо:** https://ВАШ-НИК.github.io/mono-clothing-store/

## Что умеет сайт

- Каталог из 8 товаров с фильтром по категориям
- Быстрый просмотр: выбор цвета (силуэт перекрашивается) и размера
- Корзина: количество, удаление, итоговая сумма, шкала до бесплатной доставки
- Корзина сохраняется при перезагрузке страницы (localStorage)
- Форма подписки с проверкой почты
- Светлая и тёмная тема, адаптивная вёрстка для телефона
- Плавные анимации, учтён `prefers-reduced-motion`
- Одежда нарисована векторной графикой (SVG), поэтому нет внешних картинок

## Технологии

HTML5, CSS3 (grid, flexbox, custom properties, `backdrop-filter`), JavaScript без библиотек.

## Структура

```
index.html   разметка страницы
style.css    стили и анимации
script.js    данные товаров, каталог, окно товара, корзина
```

## Как поменять товары

Все товары лежат в массиве `products` в начале `script.js`: название, цена, цвета, размеры, описание.

## Что можно доработать

- Реальные фотографии вместо SVG-силуэтов
- Оформление заказа с отправкой в Telegram через серверную часть
- Админка для редактирования каталога
